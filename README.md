# 📊 Power BI Loans Analytics Dashboard

## 📌 Project Overview
This Power BI dashboard provides comprehensive analytics on loan applications, approvals, performance, and risk metrics. It helps financial analysts and stakeholders track portfolio performance, identify default risks, and monitor overall lending operations.

---

## 📈 Key Metrics & Features
- **Loan Portfolio Overview:** Total loan amount funded, active loans, and total applications received.
- **Risk Analysis:** Default rate, Non-Performing Loans (NPL), and Delinquency trends by tenure.
- **Demographic Segmentation:** Analysis by borrower income, employment length, credit score grade.
- **Loan Status & Performance:** Breakdown of Fully Paid, Current, and Charged-Off/Defaulted loans.
